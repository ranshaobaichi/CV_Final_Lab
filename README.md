# 概述

这个仓库专用于计算机视觉课程期末论文完成，论文要求如下：

◼ 综述性研究报告：针对一个专门话题，进行深入调

研分析，形成一篇高质量的综述。

◼ 培养：查阅文献，阅读文献，撰写文献的能力，可

能启发对某个方向深入研究的兴趣。

◼ 提交格式：CVPR论文格式，建议英文撰写。

◼ 调研范围：顶级会议和顶级期刊论文，以及最新的

arXiv论文，

◼ 不要仅仅去看一些公众号、知乎、中文博客
